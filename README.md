# Сайт «Спето в КнАГУ»

Статический сайт, который можно разместить на GitHub Pages без сервера.

## Как опубликовать

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файлы:
   - `index.html`
   - `style.css`
   - `songs.js`
   - `app.js`
3. В GitHub откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки. GitHub выдаст адрес опубликованного сайта.

## Как добавить ваши тексты

Откройте `songs.js`. У каждой песни есть поля `lyrics` и `chorus`.
Вставьте туда ваш собственный текст, например:

```js
{
  title: 'Моя песня',
  artist: 'Мой исполнитель',
  lyrics: 'Куплет 1...\n\nКуплет 2...',
  chorus: 'Мой припев...'
}
```

Сайт автоматически покажет текст при раскрытии песни. Поиск также работает автоматически.

## Важно

В текущей версии тексты сторонних песен намеренно не встроены. Для публикации полного текста песни используйте текст, на который у вас есть право публикации (например, ваш собственный текст или текст, предоставленный правообладателем).
